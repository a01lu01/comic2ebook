# Comic2Ebook 改进方案（小改：保持架构与打包方式）

## 1. 目标与范围

### 目标
- 提升稳定性：遇到异常输入/Calibre 不可用/文件权限问题时不崩溃、能明确报错
- 提升可用性：页序更可靠、输出更可控、日志更可追踪
- 提升离线可用：打包后的 EXE 不依赖外网 CDN
- 保持现状约束：尽量不调整 Electron 安全模型与目录结构，继续使用 electron-packager

### 非目标
- 不做大规模工程化重构（不引入复杂构建系统、不拆分大量文件）
- 不做跨平台（仍以 Windows 10/11 为主）

## 2. 当前问题清单（基于现代码）

- JSZip 来自 CDN：离线/网络受限时 CBZ 打包可能不可用
- 图片排序使用字典序 sort：`1.jpg 2.jpg 10.jpg` 页序可能错乱
- 读图采用 base64 往返：大页数时占用内存与耗时明显
- Calibre 路径仅“猜测”：对便携版/自定义安装路径不友好
- 失败提示与日志：转换失败后缺少“一键导出日志/定位原因”的路径
- 转换参数：TECHNICAL.md 中写的部分 PDF 参数未必在代码中落地，表现可能不一致

## 3. 方案概述（小改的做法）

### 3.1 离线化 JSZip（高优先级）
- 将 JSZip 固化到仓库内：例如放置 `vendor/jszip.min.js`
- app.html 从本地引用 `vendor/jszip.min.js`（不再走 CDN）
- 验收标准
  - 断网情况下仍能正常打包 CBZ
  - 打包后 EXE 在无外网环境可用

### 3.2 图片自然排序（高优先级）
- 在主进程 `fs:list-images` 中替换 `.sort()` 为“自然排序”
- 规则建议
  - 按文件名拆分数字段与文本段：数字段按数值比较，文本段按 localeCompare
  - 同名不同扩展（jpg/png）按扩展名稳定排序
- 验收标准
  - `001.jpg, 002.jpg, 010.jpg` 顺序正确
  - `1.jpg, 2.jpg, 10.jpg` 顺序正确

### 3.3 减少 base64 往返（中高优先级）
保持“渲染进程用 JSZip 打包”的前提下，做最小改动：
- 将 IPC `fs:read-image` 返回值从 base64 改为二进制（Buffer/Uint8Array/ArrayBuffer）
- 渲染进程直接把二进制喂给 JSZip
- 验收标准
  - 大文件夹（例如 500 张 4K 图）内存峰值明显下降
  - 打包速度提升或至少不下降

### 3.4 Calibre 路径可配置（中高优先级）
- UI 增加一个“Calibre 路径”设置项（选择 `ebook-convert.exe`）
- 用最小依赖方式持久化（localStorage 或写一个 json 到 userData）
- `calibre:check` 逻辑优先级
  1) 用户配置路径（若存在且可执行）
  2) PATH 中的 `ebook-convert`
  3) 默认安装目录猜测
- 验收标准
  - 未安装 Calibre 时提示明确并给出下载入口
  - 安装路径非默认时可通过手动选择成功工作

### 3.5 错误处理与可观测性（中优先级）
- 主进程：IPC handler 全部捕获异常，统一返回 `{success:false, error:{code,message,detail}}`
- 渲染进程：每个漫画任务显示
  - 当前阶段（打包/转换/完成/失败）
  - 错误摘要（可复制）
  - “展开详情”展示日志片段
- 增加“导出日志”按钮：保存为 `Comic2Ebook-logs-YYYYMMDD-HHMMSS.txt`
- 验收标准
  - 任一任务失败不影响其它任务继续
  - 用户可一键导出日志用于反馈

### 3.6 输出命名与覆盖策略（中优先级）
- 默认策略：若目标文件已存在
  - 追加 `(1) (2) ...` 或时间戳，避免静默覆盖
- 对 folderName 做基础清洗（Windows 保留字符）
- 验收标准
  - 遇到同名输出不会丢文件
  - 文件名包含特殊字符也能正常输出

## 4. 实施步骤（建议顺序）
1) 本地化 JSZip
2) 自然排序
3) 二进制读图替代 base64
4) Calibre 路径可配置 + 检测提示优化
5) 错误结构化 + 日志导出
6) 输出命名与覆盖策略

## 5. 测试计划
- 功能测试
  - 单文件夹：仅 CBZ / CBZ+PDF / 仅 EPUB 等组合
  - 多文件夹批量：成功/失败混合
- 边界测试
  - 文件名乱序、包含数字、包含中文、包含特殊字符
  - 超大页数（>1000）与超大图片（>10MB/张）
  - Calibre 缺失/路径错误/执行失败
- 离线测试
  - 断网运行仍可打包 CBZ

## 6. 风险与回滚
- 风险：二进制 IPC 传输在大文件时可能触发性能/序列化问题
- 缓解：如果出现问题，可回退为 base64（保留兼容开关）
- 回滚策略：每步改动都可单独回退，不影响其它改进
