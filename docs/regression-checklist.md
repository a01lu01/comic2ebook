# Comic2Ebook 回归检查清单

> 每次 Phase 改动完成后，按此清单逐项验证。通过打 ✓，失败标 ✗ 并在备注中记录问题。

---

## 测试环境要求

- [ ] Windows 10/11 系统
- [ ] Node.js 已安装（`npx electron .` 可用）
- [ ] Calibre 已安装（至少 `ebook-convert` 在 PATH 中）
- [ ] 样例数据目录 `samples/` 已生成（运行 `python scripts/gen-samples.py`）
