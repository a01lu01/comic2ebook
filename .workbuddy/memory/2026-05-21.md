## Comic2Ebook — Phase 1 完成

**P1-01 JSZip 本地化**
- npm install jszip@3.10.1 --no-save，复制 dist/jszip.min.js (97KB) 到 vendor/
- app.html 第 223 行 CDN 引用替换为 `../vendor/jszip.min.js`

**P1-02 自然排序**
- main.js：新增 naturalSort() 函数，正则拆分数字/文本段逐段比较
- fs:list-images 的 .sort() 替换为 .sort(naturalSort)
- app.html：新增 naturalSort() 副本，addComicFolder 客户端排序同步替换

**P1-03 输出命名清洗**
- main.js：新增 sanitizeFilename()，清洗 Windows 保留字符 `<>:"/\|?*`
- calibre:convert handler 中 srcPath/dstPath 使用清洗后的 safeName

**P1-04 覆盖策略**
- main.js：新增 resolveOutputPath()，检测目标文件存在则自动追加 (1)(2)... 后缀
- fs:write-file 和 calibre:convert 均使用此策略
- 返回 renamed 字段告知渲染进程实际文件名

**P1-05 Calibre 参数集中化**
- main.js：定义 CALIBRE_PROFILES = {recommended, compatible}，每种格式独立参数数组
- buildCalibreArgs(format, profile) 函数拼接通用+专用参数
- calibre:convert 接受可选 profile 参数，默认 'recommended'

**P1-06 错误结构化返回**
- main.js：新增 ipcWrap(fn) 高阶函数，统一 try/catch 返回 {success, data/error}
- 全部 8 个 IPC handler 用 ipcWrap 包裹
- app.html：新增 ipcData(result) 解包函数，所有 invoke 调用点从 `const data = result` 改为 `const data = ipcData(result)`
- calibre:convert 内部返回 {ok, exitCode, path, ...}，渲染层 ipcData 后检查 .ok

**语法验证**：node -c main.js ✅，app.html JS 块 ✅
